# Трекер погоды: GitHub Pages + Supabase

Сайт хранится на GitHub Pages, записи лежат в базе Supabase. Вход по почте и паролю, у каждого пользователя свои записи.

Файлы:

- `index.html` — сам сайт
- `config.js` — адрес проекта Supabase и публичный ключ
- `schema.sql` — таблица и правила доступа для базы

## 1. Supabase

1. Создайте проект на supabase.com.
2. Откройте **SQL Editor**, вставьте содержимое `schema.sql` и нажмите **Run**.
3. Откройте **Project Settings → API** (в новых проектах раздел может называться **Connect**) и скопируйте:
   - **Project URL**;
   - публичный ключ: **anon public** или **publishable**.
4. Впишите оба значения в `config.js`.

Ключ `service_role` (он же secret) в `config.js` вписывать нельзя. Публичный ключ в репозитории хранить безопасно: доступ к данным ограничивают правила RLS из `schema.sql`.

## 2. GitHub Pages

1. Создайте репозиторий на github.com.
2. Загрузите в него `index.html`, `config.js` (и по желанию `README.md`, `schema.sql`).
3. В репозитории откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту-две сайт появится по адресу вида `https://ваш-ник.github.io/название-репозитория/`.

## 3. Адрес сайта в Supabase

В Supabase откройте **Authentication → URL Configuration** и впишите адрес сайта с GitHub Pages в **Site URL**. Иначе ссылки из писем подтверждения могут вести не туда.

## 4. Первый вход

1. Откройте сайт, введите почту и пароль (от 6 символов), нажмите **Создать аккаунт**.
2. Если в Supabase включено подтверждение почты, подтвердите её по письму и затем нажмите **Войти**.
3. Чтобы посторонние не создавали аккаунты, после создания своего отключите регистрацию в **Authentication** (настройка вроде **Allow new users to sign up**; точное название зависит от версии панели). Даже с чужим аккаунтом ваши записи не видны, но лишние пользователи не нужны.

## 5. Перенос записей из версии в Claude

1. В старой версии внизу страницы нажмите **Данные для переноса** и скопируйте весь текст.
2. На новом сайте внизу нажмите **Экспорт и импорт данных**, вставьте текст в поле и нажмите **Загрузить из текста**.

Записи с одинаковой датой и временем суток обновляются, а не дублируются. Эту же панель можно использовать как резервную копию: **Показать мои данные** выводит все записи текстом.

## Что важно знать

- Единицы давления (мм рт. ст. или гПа) запоминаются в браузере на каждом устройстве отдельно, в базе давление хранится в гПа.
- Бесплатные проекты Supabase могут приостанавливаться при долгом отсутствии активности. Если сайт перестал загружать записи, проверьте проект в панели Supabase.
